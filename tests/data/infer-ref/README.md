# infer-ref — reference data of the native inference

Generated by [tools/infer-ref/make_reference.py](../../../tools/infer-ref/make_reference.py),
the Qwen3 datasets by
[tools/infer-ref/make_reference_qwen3.py](../../../tools/infer-ref/make_reference_qwen3.py)
(environment and fixed settings: [tools/infer-ref/README.md](../../../tools/infer-ref/README.md)).
Read by the suite `infer.tests` (`tests/test.infer.ref.pas`). None of these files is
changed by hand.

## Format

Each dataset is a folder with `manifest.json` and `tensors.bin`:
- `tensors.bin` holds the tensors as raw little-endian values, one after the other,
  4-byte aligned;
- `manifest.json` describes each tensor with `name`, `dtype` (`f32`, `i32` or `u8`),
  `shape` (row-major, C order), `offset`, `bytes` and `sha256`. It also holds the
  hashes of the whole file, model revision, environment and pipeline, plus the time of
  generation. The blobs are reproducible, the manifests are not, because of this timestamp.

On opening, the loader checks the hash of the file, the position and length of each tensor
and the product of the shape before it reads anything. A computed result is never compared
by hash, but element by element: `|a − r| ≤ atol + rtol·|r|`, plus cosine and norms.
